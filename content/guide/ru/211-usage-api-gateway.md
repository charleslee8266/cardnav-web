# 2.1 API-шлюзы

> Материал подготовлен **CardNav [cardnav.xyz](https://cardnav.xyz)**.

API-шлюз предоставляет точку доступа к моделям через стороннего провайдера. После покупки квоты пользователь вводит API Key — ключ для вызовов — и Base URL — адрес интерфейса — в совместимый клиент или программу. Совместимость с OpenAI, список моделей и функций следует уточнять в документации сервиса.

## Основные преимущества

- **Ниже порог входа**: Обычно не нужны зарубежный номер телефона и банковская карта; достаточно зарегистрироваться и пополнить баланс.
- **Разные способы оплаты**: Оплата по использованию подходит для редких запросов без расходов на месячную подписку; некоторые платформы предлагают подписки или пакеты с лимитами, поэтому учитывайте правила списания.
- **Несколько моделей в одном интерфейсе**: Многие шлюзы объединяют GPT, Claude, Gemini и DeepSeek.
- **Удобное подключение инструментов**: Chatbox, Cherry Studio, расширения для кода и внутренние скрипты часто подключаются быстро.

## Ограничения и риски

- **Меньше контроля над конфиденциальностью**: Запросы проходят через провайдера шлюза. Не передавайте секретные данные, коммерческую тайну и особо чувствительную личную информацию.
- **Качество моделей требует проверки**: Возможны неясные названия, подмена сильной модели более слабой, ограничение скорости и сокращение контекста.
- **Неполный контроль над стабильностью**: Сервис может прерваться из-за квот, ограничений аккаунта, изменений исходного сервиса или проблем оператора.
- **Риск остатка на балансе**: Не вносите крупные суммы до проверки качества сервиса и работы поддержки.

## Кому подходит

- Для сравнения качества и стоимости нескольких моделей
- Для несекретных диалогов, отладки кода, перевода и подключения инструментов
- Тем, кто хочет сократить регистрацию и оплату у поставщиков моделей
- Небольшим командам для проверки прототипа до развёртывания собственного сервиса

## Порядок подключения

1. Выберите шлюз под свои задачи. Проверьте модели, цены, условия возврата и контакты.
2. Зарегистрируйтесь и начните с небольшой суммы.
3. Создайте API Key в панели управления, уточните Base URL, названия моделей и правила оплаты.
4. Укажите ключ и адрес шлюза в Chatbox, Cherry Studio, расширении для кода или своём скрипте.
5. Проверьте скорость, функции и списания на типичных задачах. Простые вопросы не доказывают, какая модель работает на стороне провайдера.
6. При длительном использовании пополняйте баланс по фактической потребности и держите запасной сервис на случай отказа основного.

## Рекомендации

API-шлюзы подходят для сравнения моделей и подключения инструментов. При работе с данными клиентов, внутренним кодом или чувствительной личной информацией проверяйте правила хранения, использования для обучения и доступа как у посредника, так и у исходного сервиса. Собственный шлюз не устраняет риски обработки данных поставщиком модели. Для важных задач также нужны план действий при сбое и возможность перенести настройки подключения.
