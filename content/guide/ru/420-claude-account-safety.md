# Безопасность аккаунта Claude и обжалование

> Материал подготовлен **CardNav [cardnav.xyz](https://cardnav.xyz)**.

Если Claude недоступен, определите по сообщению на экране, связана ли проблема со входом, лимитом или отключением аккаунта. Полный текст ошибки и время возникновения помогут найти причину и объяснить ситуацию официальной поддержке.

## Как определить тип проблемы

| Сообщение или признак | Что делать |
| --- | --- |
| Достигнут лимит, указано время сброса | Проверьте остаток и время сброса, при необходимости дождитесь восстановления или смените тариф |
| Ошибка запроса, сервис недоступен | Проверьте статус сервиса, сеть и версию клиента, сохраните исходную ошибку |
| Требуется проверка личности или безопасности | Уточните требования через официальный канал; не передавайте документы и коды посредникам |
| Явное ограничение или отключение аккаунта | Сохраните уведомление и запросите пересмотр официальным способом |
| Приостановлена отдельная организация | Используйте форму пересмотра на странице ограничения этой организации |

Исчерпанный лимит и отключение аккаунта требуют разных действий. Ошибка запроса сама по себе не подтверждает блокировку. Если причина не указана, не следует самостоятельно связывать её с IP, оплатой или частотой использования.

## Повседневное обслуживание аккаунта

Сохраняйте контроль над почтой и способами восстановления, защищайте учётные данные и не передавайте их другим. Храните заказы подписки, платёжные документы и записи об оплате через продавцов для проверки доступа и обращения в поддержку. Важный код, файлы и материалы проектов сохраняйте отдельно, чтобы неполадки аккаунта не прервали работу.

До использования Claude проверьте официально поддерживаемые регионы и требования к аккаунту. Проверка IP даёт сведения о сети, но не подтверждает право пользоваться сервисом. Смена часового пояса, домашний IP или редкое использование нового аккаунта также не гарантируют отсутствия ограничений.

Обычные задачи Claude Code могут включать автоматизацию и вызов инструментов. Допустимость определяется правилами продукта; длительность или частота работы сами по себе не доказывают нарушение.

## Разрешения и расход в Claude Code

Проверьте текущий аккаунт Claude Code, подключённый сервис и соответствующий счёт. Включённый объём, дополнительное использование и расходы API учитываются отдельно.

| Способ использования | Что проверить |
| --- | --- |
| Официальная подписка | Наличие нужных функций в тарифе и достижение лимита |
| Дополнительное использование | Включено ли оно и как рассчитывается оплата |
| Официальный API | Используемый аккаунт API и его отдельный счёт |
| Сторонний шлюз | Баланс, тарификацию, конфиденциальность и правила поддержки посредника |

В официальном Claude Code команда `/usage` показывает расход. Оценка стоимости сеанса не обязательно равна дополнительному списанию с аккаунта подписки. Ориентируйтесь на соответствующие страницы расхода и платежей, чтобы не пополнять счёт без необходимости.

Данные подписки следует использовать только в разрешённых официально клиентах и целях, а программный доступ — по применимым правилам API. За баланс и обязательства стороннего шлюза отвечает его поставщик; проверяйте их отдельно от возможностей официальной подписки.

## Обжалование и сохранение данных

При явно установленном ограничении:

1. **Соберите сведения.** Сохраните уведомление, время, версию клиента и связанные заказы. Удалите из снимков и вложений пароли, коды, данные входа и другую конфиденциальную информацию.
2. **Используйте официальный канал.** По инструкции войдите в ограниченный аккаунт и подайте запрос на пересмотр. Для приостановленной организации следуйте указаниям её страницы.
3. **Правдиво опишите использование.** Укажите назначение аккаунта, обстоятельства и выполненную диагностику. Если причина не названа, описывайте признаки без догадок и шаблонов с чужим опытом.
4. **Сохраните доступные материалы.** Используйте экспорт на странице аккаунта. Возможность экспорта и состав доступных данных определяются текущими опциями этой страницы.

Обжалование и возврат решаются отдельно. За возвратом обращайтесь в канал покупки; во время рассмотрения не обходите ограничения созданием новых аккаунтов.
