# Claude subscriptions and top-ups

> This article is provided by **CardNav [cardnav.xyz](https://cardnav.xyz)**.

Before buying a Claude subscription, decide whether you need web and app features, Claude Code usage or API credits. Their access methods and bills are not interchangeable.

## Subscriptions and API billing

Pro and Max subscriptions cover Claude and Claude Code, which share the plan's usage limits. Sign in to Claude Code with the same Claude account to use its subscription. If `ANTHROPIC_API_KEY` is configured, authentication may use the API key and incur API charges.

Console/API and Claude subscriptions are billed separately. API balance is not included subscription usage for Claude or Claude Code.

## Purchase channels and activation

Website, Apple App Store and Google Play orders are managed separately. Website payment options may differ from app stores; follow the current purchase page.

1. **Confirm the account**: Sign in to the intended Claude account and check for an active subscription.
2. **Select a plan**: Review features, usage, billing period, final price and renewal method.
3. **Pay**: Follow website checkout, or start the store purchase from the official mobile app, checking the store account.
4. **Verify access**: Check plan status and retain the order. In Claude Code, confirm the account and billing method to avoid unintended API charges.

For app-store preparation, see [App Store payments](./332-payment-app-store.md) and [Google Play Store payments](./333-payment-google-play.md). If using a seller, confirm delivery and failure terms separately; see [Third-party top-ups](./213-usage-third-party-top-up.md).

## Charges and activation problems

| Situation | Action |
| --- | --- |
| Payment declined | Check card status, billing details and payment requirements as prompted; contact the issuer or official support if needed |
| Paid but account still appears free | Check whether you signed in with another email and whether the latest payment failed; contact the relevant support with the order |
| Several charges | Review website, Apple, Google Play and Console records to distinguish subscriptions, API fees and duplicate orders |
| Seller received money but did not activate | Pursue the seller under the order terms; payment to a seller does not establish receipt by Claude |

Do not repeatedly pay while the cause is unclear. Retain the order number, account email, transaction time and charge record; hide passwords and login tokens when supplying support information.

## Renewals, cancellation and refunds

Manage website purchases in Settings → Billing. For Apple or Google Play subscriptions, use the original store to manage payment methods, renewal and cancellation. Cancellation normally takes effect at the end of the current period; official guidance requires canceling at least 24 hours before the next billing date to avoid another charge.

Refunds require a separate request, with eligibility and amounts determined by the purchase channel and applicable rules. Contact Claude support for website orders; Apple reviews App Store refunds. For Google Play orders, contact Claude support with the associated email or GPA order number. Confirm both the refund request and cancellation to avoid future charges.
