# Claude Account Safety and Appeals

> This article is provided by **CardNav [cardnav.xyz](https://cardnav.xyz)**.

If Claude is unavailable, use the on-screen message to distinguish a login problem, usage limit, or account deactivation. Save the full error and the time it occurred to help troubleshoot and explain the issue to official support.

## Identifying the Type of Problem

| Message or symptom | What to do |
| --- | --- |
| Usage limit reached with a reset time | Check remaining usage and the reset time; wait or adjust the plan as needed |
| Request failure or service unavailable | Check service status, network connection, and client version; save the original error |
| Identity or security verification required | Confirm requirements through official channels; do not give documents or codes to intermediaries |
| Explicit account restriction or deactivation | Save the notice and request review through the official process |
| A particular organization is suspended | Request review using the option on that organization’s restriction page |

An exhausted allowance and a deactivated account require different responses. A failed request alone does not establish a ban. If the page gives no reason, do not assume the IP, payment, or usage frequency caused it.

## Routine Account Maintenance

Keep control of the account email and recovery methods, protect login credentials, and do not share them. Retain subscription orders, payment receipts, and third-party payment records for checking benefits or handling support. Keep separate copies of important code, files, and project data so account problems do not interrupt your work.

Before using Claude, check officially supported regions and account requirements. IP checks provide network information, not proof of eligibility. Changing time zones, using a residential IP, or reducing activity on a new account cannot guarantee it will remain unrestricted.

Normal Claude Code tasks may include automation and tool calls. Assess authorization against the product’s rules; long-running or frequent use alone does not establish a violation.

## Claude Code Authorization and Usage

Confirm the account signed in to Claude Code, the connected service, and the relevant bill. Check included usage, extra usage, and API charges separately.

| Access method | What to verify |
| --- | --- |
| Official subscription | Whether the plan includes the required features and whether usage has reached its limit |
| Extra usage | Whether it is enabled and how it is billed |
| Official API | The API account in use and its separate bill |
| Third-party gateway | The provider’s balance, billing, privacy, and support rules |

In official Claude Code, `/usage` displays usage information. Session cost estimates do not necessarily equal extra charges on a subscription account. Refer to the relevant usage and billing pages to avoid unnecessary top-ups.

Use subscription credentials only with officially permitted clients and purposes. Programmatic access must comply with the applicable API authorization rules. Third-party balances and service commitments are the provider’s responsibility and should be checked separately from official subscription benefits.

## Appeals and Saving Data

After an explicit restriction:

1. **Collect records.** Save the notice, time, client version, and relevant orders. Remove passwords, codes, login credentials, and other sensitive information from screenshots and attachments.
2. **Use the official appeal channel.** Follow official instructions to sign in to the restricted account and request review. For a suspended organization, follow its page’s instructions.
3. **Describe your use truthfully.** Explain the account’s purpose, what happened, and your troubleshooting. If no reason is given, describe the symptoms without guessing or using a template that does not match your experience.
4. **Save accessible data.** Use the export options on the account page. That page determines whether export is available and which data can be exported.

Appeals and refunds are separate processes. Contact the actual purchase channel for refunds; do not evade restrictions by creating replacement accounts during an appeal.
