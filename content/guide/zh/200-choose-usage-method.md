# 二、选择 AI 模型使用方式

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

快速试用可选中转站或成品账号；已有账号但无法付款，可考虑代充；长期重度使用优先官方订阅。具备技术条件时，自建中转可统一管理调用，自行部署则直接掌握模型运行资源。

## 2.1 API 中转站
<!-- badge="上手最快" icon="api" -->

购买调用额度，取得 API Key（调用密钥）后接入客户端或程序。

### 核心优势
- 减少注册与付款准备，小额体验多模型

### 主要风险
- 请求经过服务商；需核验模型真实性、计费与持续运营情况

### 适合人群
- 多模型试用、非敏感任务、开发调试

[点击了解详情](./211-usage-api-gateway.md)

## 2.2 成品账号
<!-- badge="开箱即用" icon="model" -->

购买商家准备好的账号或席位，按约定登录使用。

### 核心优势
- 省去注册与开通步骤，快速体验官方网页与客户端

### 主要风险
- 卖家可能保留恢复权限；需确认账号类型、有效期与售后

### 适合人群
- 短期体验、可接受账号控制权受限

[点击了解详情](./212-usage-ready-account.md)

## 2.3 第三方代充
<!-- badge="保留原号" icon="cash" -->

使用自己的账号，由商家代为开通或续费订阅。

### 核心优势
- 保留原号、记录与设置，降低付款门槛

### 主要风险
- 付款撤销导致权益失效、代操作泄露凭证的风险

### 适合人群
- 已有自用账号、暂时无法自行付款

[点击了解详情](./213-usage-third-party-top-up.md)

## 2.4 官方订阅
<!-- badge="长期可控" icon="key" -->

自行注册，通过官方支持的渠道购买订阅。

### 核心优势
- 自主管理账号、恢复方式与账单，减少商家依赖

### 主要风险
- 地区、验证与付款门槛，以及订阅费用

### 适合人群
- 长期重度使用、自主管理资料与续费

[点击了解详情](./214-usage-self-register.md)

## 2.5 自建 API 中转站
<!-- badge="技术共享" icon="vps" -->

部署统一接口，连接已有的上游模型服务。

### 核心优势
- 团队密钥与额度集中分配，多工具调用统一管理

### 主要风险
- 服务器与密钥维护、上游费用及授权限制

### 适合人群
- 具备运维能力、需要统一管理团队调用

[点击了解详情](./215-usage-self-hosted-gateway.md)

## 2.6 自行部署大模型
<!-- badge="资源自主" icon="model" -->

租用云端 GPU 算力，或使用自有、购置的设备运行模型。

### 核心优势
- 自主选择可部署模型、分配算力、管理数据存放

### 主要风险
- 技术与成本门槛高：设备或算力费用、持续维护

### 适合人群
- 具备部署能力，重视数据隐私或需要自定义模型配置

[点击了解详情](./216-usage-self-deploy-model.md)
