# ChatGPT 订阅充值

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

开通 ChatGPT 订阅前，应确认登录账号、套餐权益和付款渠道。ChatGPT 订阅与 API 分别计费，API 账户余额不能用于开通 ChatGPT 会员。

通过 ChatGPT 账号登录 Codex 时，使用对应套餐提供的 Codex 权益；通过 API Key（调用密钥）接入时，应查看对应 API 账单。购买前确认当前登录方式，不能把 API 充值当作 ChatGPT 订阅续费。

## 套餐与价格

选择 Plus、Pro 等套餐时，应根据实际使用需求比较功能、使用额度和订阅周期。套餐权益与购买资格可能调整，以账号内的套餐说明和结算页面为准。比较不同地区的价格，可参考 [官方订阅比价](https://cardnav.xyz/official-price)，同时核对币种、税费和价格更新时间。

第三方报价还需要确认账号归属、有效期、交付内容和售后范围。团队席位、多人共享账号、仅剩部分有效期的成品账号，在使用权限和期限上均可能与个人订阅不同，不宜仅按标价比较。购买前的具体检查项见 [成品账号购买与登录](./212-usage-ready-account.md)。

## 付款渠道

官网订阅与应用内订阅的付款、续费和售后入口不同。付款前应确认当前渠道支持所选套餐，并检查是否已有尚未到期的订阅，避免重复购买。

| 购买渠道 | 付款前需要确认 |
| --- | --- |
| ChatGPT 官网 | 当前登录账号、套餐、账单资料，以及结算页面支持的付款方式 |
| Apple App Store | 应用是否为官方版本、Apple 账户地区、套餐和付款方式是否可用 |
| Google Play | 应用是否为官方版本、Google 账户地区、付款资料与可订阅套餐 |
| 第三方代充 | 开通账号、订阅期限、付款方式，以及失败或未到账时的处理约定 |

通过应用商店购买时，可进一步阅读 [App Store 支付](./332-payment-app-store.md) 和 [Google Play Store 支付](./333-payment-google-play.md)。购买礼品卡前，需要确认其地区、兑换条件和余额用途；商店余额可兑换，并不代表一定能用于目标订阅。

使用第三方代充时，应由本人保管邮箱、账号恢复方式和多重验证设置。密码、验证码及 Cookie、Session 等登录凭证可能赋予他人账号访问权限，不应公开或提交给不明网站。交付与售后检查见 [第三方代充](./213-usage-third-party-top-up.md)。

## 付款异常排查

| 异常情况 | 处理方式 |
| --- | --- |
| 银行卡被拒绝，付款未完成 | 核对账单资料、卡片状态和发卡行限制，按照错误提示联系银行或官方支持 |
| 银行显示待处理，订阅未开通 | 确认是临时预授权还是已入账交易，保存交易时间和记录，避免连续重复付款 |
| 已扣费，但套餐未更新 | 核对登录账号、所在工作区和购买渠道，凭订单记录联系相应渠道的支持人员 |
| 官网和手机端均有扣款 | 分别查看官网、Apple 和 Google 的订阅记录，确认是否重复订阅 |
| 第三方商家收款后未开通 | 按订单约定向商家申请处理；商家收取的款项需通过原交易渠道追索 |

付款被拒绝时，还应检查账号与支付方式是否符合官方的地区和使用要求。更换 IP、购买礼品卡或再次充值，都不能保证解决拒付问题。

## 续费、取消与退款

取消续费、申请退款和删除账号处理的是不同事项：

- **取消续费**：停止后续自动扣款，具体生效时间和剩余使用期限以订阅页面为准。
- **申请退款**：处理已经支付的订单，是否符合退款条件、退还金额及办理方式由实际购买渠道决定。
- **删除账号**：涉及账号数据和访问权限，不应作为日常订阅管理方式。

官网购买的订阅，应在 ChatGPT 账号设置中查看管理入口；通过 Apple 或 Google 购买的订阅，应在对应商店查询和管理。办理取消或退款时，保留套餐名称、续费日期、订单号和处理结果，避免遗漏其他渠道的有效订阅。
