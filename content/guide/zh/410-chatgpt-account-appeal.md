# ChatGPT 账号申诉

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

认为 ChatGPT 账号被误停用时，可以向 OpenAI 申请复核。申诉入口取决于是否收到、能否访问停用通知邮件。

## 选择官方入口

1. **收到通知邮件**：使用邮件中的申诉链接提交，便于官方将申请对应到具体账号和处理记录。
2. **无法访问该邮件**：通过 [OpenAI 官方申诉表单](https://openai.com/form/appeal/) 提交。
3. **未收到通知，但已无法访问账号**：打开 [OpenAI 帮助中心](https://help.openai.com/)，点击右下角聊天气泡联系支持。系统会先由虚拟助手接待，无法解决时可能转交人工。

## 准备申诉材料

- **账号信息**：登录邮箱、登录方式和套餐；官方申诉说明还列有 User ID、Org ID，分别为用户与组织标识。
- **问题经过**：停用提示原文、发生日期与时区、实际用途，以及认为需要复核的相关背景。
- **已采取的措施**：说明已经完成的排查和处理；怀疑账号被盗时，提供可能遭到入侵的时间范围。官方建议更改密码并轮换 API Key。
- **异常扣款**：仅在存在未经授权的扣款时，补充扣款日期、金额、银行卡末四位、卡组织、发卡行及账单邮编。

材料应如实填写。截图和附件隐藏无关个人信息，不提供密码或一次性验证码。

## 按限制原因处理

安全风险可能导致保护性暂停；未完成身份或年龄验证也可能导致停用。收到验证要求时，应按官方通知补齐材料；找不到身份验证邮件，可联系支持重新发送。并非所有情况都适合仅提交同一份申诉说明。

提交后按官方回复补充材料。官方未承诺固定处理时长，也不保证每次申诉都能恢复账号。
