# 常见账号发货格式说明

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

商家所称的“账号”，可能指账号密码，也可能指供工具使用的登录令牌或 JSON 文件。购买前应确认交付内容、使用入口和二次验证要求。发货格式只说明资料如何组织，不能证明账号归属、订阅权益或有效期限。

需要在官网或客户端登录时，应确认商家提供有效登录资料，并说明邮箱和验证方式的归属。需要导入工具时，则应核对目标软件支持的格式与必填字段。

## 账密
<!-- badge="登录资料" icon="key" -->

账密指邮箱或用户名及登录密码。能否直接登录，取决于账号状态、登录方式与额外验证要求。

- 密码用于目标服务，还是仅用于邮箱
- 是否需要验证码，由谁接收
- 能否修改密码、邮箱与恢复方式；登录权限不等于完整账号所有权

```txt
example@example.com | abc***XYZ
```

## 四段 RT
<!-- badge="账号与令牌" icon="key" -->

四段 RT 通常将账号、密码、`client_id` 和 `refresh_token` 写在一行。前者标识相关应用，后者用于刷新访问令牌。

不同商家的字段定义可能不同，也可能属于邮箱服务。需明确对应平台与用途，不能仅凭“四段 RT”认定可用于 ChatGPT 登录或转换。

```txt
example@example.com----abc***XYZ----cli***123----rt_abc***xyz
```

直接登录需有效账密及必要验证；工具使用令牌则取决于授权对象、有效状态和格式支持。

## ChatGPT Session
<!-- badge="会话 JSON" icon="api" -->

Session 是登录会话信息，可导出为 JSON 供兼容工具使用，不能当作账密填入登录表单。

```json
{
  "user": {
    "id": "user_abc***xyz",
    "email": "example@example.com"
  },
  "account": {
    "id": "acct_abc***xyz",
    "planType": "plus"
  }
}
```

示例仅展示部分结构，不含完整凭证，不能直接导入。套餐名称不证明订阅有效，需查看实际账号状态。

## Codex / CPA / Sub2API / Cockpit
<!-- badge="工具导入格式" icon="toolbox" -->

这些名称可见于工具导入说明。字段随工具、版本和商家而异，不是通用格式。

```json
{
  "refresh_token": "rt_abc***xyz",
  "access_token": "eyJ***xyz",
  "email": "example@example.com"
}
```

`access_token` 通常用于访问获授权的服务，`refresh_token` 用于获取新访问令牌。示例值均为占位内容，可能缺少目标工具要求的其他字段。

购买前确认目标工具、版本、导入方式与有效期。可导入不代表能网页登录、修改资料或恢复账号。

## 格式转换与凭证保管

转换格式只能重新组织已有资料，不能补出缺失的密码、授权或订阅权益。转换前应核对来源格式、目标工具要求和字段含义；仅有账号密码，也不代表可以直接生成任意工具所需的令牌。

登录令牌和会话凭证应按密码妥善保管。将其提交给第三方网站或导入不可信工具，可能使他人获得账号访问权限。公开截图、求助或反馈问题前，应删除密码和令牌等敏感字段。

## 下单确认

- **使用入口**：在官网、官方客户端还是指定第三方工具中使用
- **完整资料**：是否包含所需字段，是否需要邮箱验证码或其他验证
- **账号权限**：能否管理邮箱、密码和恢复方式，是否属于共享或团队席位
- **期限与售后**：订阅及凭证的有效期，失效后的补发或退款条件
