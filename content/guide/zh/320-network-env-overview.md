# 3.2 网络环境与主机准备

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

注册、登录和订阅 AI 服务时，网络连接、服务地区资格与账号验证需要分别确认。能够打开网站，不代表一定符合注册或付款条件。日常使用通常只需准备合适的网络连接；部署自建服务时，才需要进一步考虑云服务器及维护成本。

## 科学上网与 VPN
<!-- badge="网络连接" icon="vpn" -->

VPN 或代理提供网络连接，按服务可达性、线路、设备支持和费用选择，并核对支持地区。

### 适合场景
- 访问 AI 网页、客户端和 API
- 排查连接失败、延迟或网络中断

### 注意事项
- 用常用设备和网络试用后再长期订阅
- 网络连通不代表满足账号与地区资格

[查看网络工具选择](./321-tool-vpn.md)

## 云服务器租用
<!-- badge="自建基础" icon="vps" -->

VPS 为自建节点和 API 中转提供持续运行的主机，配置灵活，更新、安全与故障需自行处理。

### 适合场景
- 部署自建节点或内部中转服务
- 自行管理配置、权限和资源

### 注意事项
- 按程序需求选配置，不只比较价格
- 兼顾线路、流量、续费和维护能力

[查看云服务器选择](./322-tool-vps.md)

## IP 纯净度检查
<!-- badge="辅助排查" icon="shield-alert" -->

查看出口地区、网络类型与风险记录，辅助排查异常；检测评分不等于平台审核结果。

### 适合场景
- 确认当前网络出口
- 排查登录失败或频繁验证
- 核对付款时的网络地区

### 注意事项
- 不同数据源可能有差异
- 低风险评分不保证注册、登录或付款成功

[了解 IP 检查](./323-tool-ip-check.md)

## 海外手机号验证
<!-- badge="账号验证" icon="phone" -->

手机号不只是注册时收一次验证码，也可能在后续登录、改密、换设备或风控复核时再次被要求验证。

### 适合场景
- 平台明确要求短信验证
- 长期账号的持续验证与恢复

### 注意事项
- 临时接码难以保证再次使用原号码
- 长期号码需核对适用范围、收码条件和保号费

[了解手机号验证](./324-tool-phone-verification.md)
