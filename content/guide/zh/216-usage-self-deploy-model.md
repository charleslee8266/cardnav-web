# 2.6 自行部署大模型

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

自行部署大模型，是将模型权重下载到自己管理的设备上运行。权重是模型训练后形成的参数文件；使用它生成回答叫“推理”，不需要从头训练模型。API 中转只负责转发请求，模型仍由上游服务运行，两者对算力和维护的要求不同。

这条路径适合重视数据隐私，或需要自定义运行环境、模型版本的用户，成本和技术门槛较高。只能部署发布了可下载权重、且许可允许相应用途的模型；GPT、Claude 等闭源在线模型不能直接下载部署。

## 部署前选择模型

GPU 即图形处理器，擅长模型推理中的并行计算；显存是 GPU 使用的内存，需要容纳模型和运行中的数据。模型越大、一次处理的文本越长，通常需要越多显存。

量化是用较低精度保存模型参数，以减少文件大小和内存占用，可能影响回答质量。新手宜选择工具已支持的小型对话模型或量化版本，先完成运行验证，再考虑更大的模型。下载前查看模型说明中的用途、许可、文件格式和资源需求，不能只根据模型名称决定购买硬件。

## 租用云端 GPU 算力
<!-- badge="按需租用" icon="vps" -->

### 适合谁

短期实验、大显存需求或购机前试用。平台提供 GPU 主机，用户负责模型下载、推理和访问管理。

### 操作步骤

1. 按模型要求选择 GPU、显存和存储，采用平台推理模板，减少驱动安装工作。
2. 确认计费方式和预算提醒，通过控制台或 SSH 连接主机，按工具文档安装、启动服务。
3. 从发布方下载指定版本的权重，存入持久磁盘，按模型说明设置路径和启动参数。
4. 在主机内发送短问答，检查回答和日志。远程访问须使用受保护的连接，并设置接口认证。
5. 测试后保存配置和数据，停止或释放实例，检查剩余存储费用。

### 成本

按 GPU 使用时间、存储及网络计费。Runpod 停止 Pod 后，保留的卷磁盘仍收费；关闭网页不会结束实例。任务完成后及时停机。

## 使用自有电脑或购买设备
<!-- badge="本地运行" icon="model" -->

### 适合谁

经常使用、需要离线运行或资料留在本机的用户。可用现有设备试用后再购机。

### 操作步骤

1. 查看系统、内存和显卡，按 LM Studio 的硬件支持说明安装对应版本。
2. 在模型搜索页选择兼容且适合现有资源的模型；多个量化版本按大小与质量取舍，不必选最大版本。
3. 下载、加载模型，新建聊天发送短问题。内存不足时，换小模型或缩短上下文，即一次保留和处理的文本量。
4. 用真实写作、代码或文档任务验证效果、速度和连续运行情况，观察内存占用。命令行或程序接入可参考 Ollama 文档。

### 成本

计入显卡、整机配套、内存、硬盘、电源、散热和电费。显存影响模型容纳能力，速度还取决于硬件和运行方式；购机前可租用相近配置验证需求。

## 如何判断部署成功

模型能够加载、完成真实任务，并在连续使用时保持可接受的速度，才适合继续投入。保留模型版本、配置和测试结果；回答质量不足时，优先比较模型与量化版本，单纯增加硬件不会自动改善模型能力。
