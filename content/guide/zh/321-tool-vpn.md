# 科学上网与 VPN

> 本文由 **卡网大全 [cardnav.xyz](https://cardnav.xyz)** 提供。

使用 AI 网页、客户端或 API 时，网络工具的选择应围绕连接质量、设备兼容和维护成本。VPN 或代理可以改变网络连接路径，但能否使用目标服务，还取决于平台的支持地区和账号要求。

## 如何选择网络方案

| 方案 | 适用情况 | 需要承担的成本 |
| --- | --- | --- |
| 订阅代理服务 | 希望使用现成节点，减少配置和维护 | 订阅费用，以及服务商线路变化和共享出口带来的不确定性 |
| 云主机自建节点 | 有服务器管理能力，需要自行管理配置 | 主机费用、部署维护、安全更新和故障处理 |

共享节点的连接质量会受线路与使用负载影响，自建节点也受机房、运营商和服务器配置限制。独立 IP 或自建 VPS 均不能保证账号安全。

试用时应在常用设备和实际网络下检查网页、客户端及 API 的连接情况，关注常用时段的延迟、中断情况和流量限制。付款前确认套餐有效期、续费价格、设备数量及售后规则。
