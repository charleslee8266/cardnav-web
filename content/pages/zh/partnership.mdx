# 商务合作

卡网大全为 AI 账号、卡网商品和 API 中转站提供搜索与导航，帮助用户比较信息后进入商家网站。

## 合作方式

<TwoColumn class="partnership-grid">
<Card tone="primary">

### 方式一：Affiliate 返佣合作

适合支持 Affiliate 的中转站和卡网。

1. 商家提供 Aff 链接，或卡网大全注册获取。
2. 卡网大全展示 Aff 链接（不承诺固定展示位置）。
3. 用户点击 Aff 链接进入商家站点使用。
4. 商家按成交额返利，建议 5%~20%。

</Card>

<Card tone="teal">

### 方式二：小额赞赏

适合希望支持卡网大全维护的用户和商家。

1. 用户或商家自助参与<a href="/supporters?support-dialog">小额赞赏</a>。
2. 赞赏到账后，将展示在<a href="/supporters">赞赏名单</a>中。
3. 商家赞赏可关联对应<a href="/llm-gateway">中转站</a>或<a href="/shops">卡网站点</a>，有机会获得置顶展示，具体规则见下方。

</Card>

<Card tone="gold">

### 方式三：固定合作商家

适合需要更多曝光的商家。

1. 商家提供必要信息。
2. 按月支付合作费用，详情请<a href="https://t.me/cardnav_xyz_group" target="_blank" rel="noopener noreferrer">私聊</a>。
3. 卡网大全在固定位置展示。
4. 卡网大全可提供点击数据。

</Card>
</TwoColumn>

## 规则详情

<TwoColumn class="partnership-details">
<DetailPanel>

### 赞赏商家展示规则

1. **展示位置**：在<a href="/llm-gateway">中转站页面</a>和<a href="/shops">卡网页面</a>中，筛选参数匹配时置顶展示商家或部分商品，并标注“赞赏商家”。
2. **展示数量**：赞赏置顶区最多展示 10 条，单个商家最多展示 2 条。
3. **当前排序**：按商家近期赞赏积分从高到低展示。
4. **排序规则**：按每笔已到账赞赏分别计算赞赏积分并汇总，再按汇总积分从高到低排序。单笔积分 = 赞赏金额（人民币元）× 0.5<sup>经过天数 ÷ 30</sup>；仅计算一年内的赞赏，30 天后单笔贡献减半。每日刷新积分，个人赞赏不参与商家置顶排序。

</DetailPanel>

<DetailPanel>

### 固定合作展示规则

1. **赞助商列表**：在所有页面展示，**商家需提供图片素材，宽高 3:1**。
2. **表格置顶区**：在<a href="https://cardnav.xyz/llm-gateway" target="_blank" rel="noopener noreferrer">中转站页面</a>和<a href="https://cardnav.xyz/shops" target="_blank" rel="noopener noreferrer">卡网页面</a>中，筛选参数匹配时置顶展示商家或部分商品，并标注“合作商家”。
3. **官方群**：可在<a href="https://t.me/cardnav_xyz_group" target="_blank" rel="noopener noreferrer">官方 TG 群</a>发布推广链接并置顶。
4. **其他**：实际展示效果可参考已有商家，例如 `GeniusCoder`；如有其他需求，也可以<a href="https://t.me/cardnav_xyz_group" target="_blank" rel="noopener noreferrer">详细讨论</a>。

## 合作要求与用户判断

<TwoColumn class="partnership-columns">
<DetailPanel>

### 合作要求

1. 网站可访问，商品等信息真实清晰
2. 提供客服群或频道，供卡网大全观察，并保持可用
3. 不得提供钓鱼、仿冒、恶意跳转、欺诈或高风险内容
4. 不得隐藏合作关系或伪装自然排名

</DetailPanel>

<DetailPanel>

### 用户判断

1. 合作仅代表卡网大全已完成初步审核，不代表对商家经营、履约或售后作出保证
2. 用户还需自行核对域名、商品、价格、支付、客服和售后
4. 如发现欺骗、恶意跳转、高风险等内容，将下架展示并暂停或终止合作

</DetailPanel>
</TwoColumn>
