# Партнёрство

CardNav помогает находить AI-аккаунты, магазины цифровых товаров, API gateway и связанные сервисы. Пользователь сравнивает информацию перед переходом на сайт продавца.

## Варианты партнёрства

<TwoColumn class="partnership-grid">
<Card tone="primary">
### Вариант 1: Affiliate-партнёрство

Для gateway и магазинов с Affiliate-системой.

1. Продавец предоставляет Aff-ссылку или CardNav регистрируется и получает её.
2. CardNav размещает Aff-ссылку (фиксированное место не гарантируется).
3. Пользователь переходит по Aff-ссылке на сайт продавца и использует его.
4. Продавец выплачивает комиссию с завершённых продаж; рекомендуется 5%~20%.
</Card>

<Card tone="teal">
### Вариант 2: Фиксированное партнёрство

Для продавцов, которым нужно больше показов.

1. Продавец предоставляет необходимые сведения.
2. Продавец ежемесячно оплачивает партнёрство; [подробности уточняются лично](https://t.me/cardnav_xyz_group).
3. CardNav размещает продавца в фиксированных позициях.
4. CardNav может предоставить статистику переходов.
</Card>
</TwoColumn>

## Детали фиксированного партнёрства

<TwoColumn class="partnership-details">
<DetailPanel>
### Материалы для фиксированного партнёрства

1. **Название**: для заголовка страницы и отметки о партнёрстве
2. **Описание**: краткая информация о сервисе
3. **Сайт**: для проверки и переходов пользователей
4. **Изображение**: соотношение сторон 3:1, для списка спонсоров и других размещений
</DetailPanel>

<DetailPanel>
### Правила размещения фиксированного партнёра

1. При совпадении фильтров продавец или отдельные товары закрепляются вверху [страницы gateway](https://cardnav.xyz/llm-gateway) и [страницы магазинов](https://cardnav.xyz/shops) с отметкой «Партнёр».
2. Список спонсоров размещается внизу каждой страницы; продавец предоставляет изображение.
3. Пример отображения можно посмотреть у `GeniusCoder`.
4. Другие требования можно [обсудить отдельно](https://t.me/cardnav_xyz_group).
</DetailPanel>
</TwoColumn>

## Требования и самостоятельная оценка

<TwoColumn class="partnership-columns">
<DetailPanel>
### Требования к партнёрству

1. Сайт доступен, информация о товарах понятна и достоверна
2. Доступна группа или канал поддержки для наблюдения со стороны CardNav
3. Запрещены фишинг, имитация других сайтов, вредоносные перенаправления, мошенничество и другие опасные материалы
4. Партнёрство нельзя скрывать или выдавать за естественное ранжирование
</DetailPanel>

<DetailPanel>
### Самостоятельная оценка пользователя

1. Партнёрство означает, что CardNav провёл первичную проверку; оно не гарантирует работу продавца, исполнение заказа или поддержку
2. Пользователю следует самостоятельно проверить домен, товары, цены, оплату, поддержку и послепродажное обслуживание
3. Обман, вредоносные перенаправления и другие опасные действия могут привести к удалению продавца и прекращению партнёрства
</DetailPanel>
</TwoColumn>
